# REVENTÓN

**Revienta. Voltea. Repite.** Pop-it antiestrés en 3D para el navegador.

Juega: https://gamexic.github.io/reventon/

- Toca o desliza para reventar burbujas de silicona; con «Voltear» el tablero gira y las reventadas quedan infladas del otro lado.
- 8 mundos listos y todo combinable: 9 formas, 11 paletas, 7 materiales, 6 sonidos, 6 efectos, 3 tipos de burbuja y 3 cantidades.
- El sonido cambia con el material elegido. Vibración en móviles Android.
- Responsive: móvil, tablet y escritorio.

Un solo archivo (`index.html`) con three.js desde cdnjs.
